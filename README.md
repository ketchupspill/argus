# luma
a program designed to assist you in clarifying, simplifying and streamlining your daily duties.

The idea behind luma is that a traditional to-do list requires too much work from YOU to setup. You enter your tasks, their due dates, manually set priorities, move them around into folders. 

By the time you're done all that organising you're already behind on the task.

Luma aims to circumvent this shortcoming. Implementation of a ML aspect will allow your task entries to be simple, but also be stored efficiently and in a easily understandable manner.
